## Construction Company Website — Technology Stack

### Frontend
- **HTML:** Semantic HTML5
- **CSS:** Vanilla CSS3 with CSS custom properties (variables), Flexbox, and CSS Grid
- **JavaScript:** Vanilla ES6+ (no frameworks)
- **Fonts:** Google Fonts (recommended: Montserrat for headings, Open Sans for body)
- **Icons:** Font Awesome (CDN) or inline SVGs

### Design System
- **Color Palette:**
  - Primary: `#1A1A2E` (deep navy — authority, trust)
  - Accent: `#E8A020` (construction amber — energy, action)
  - Surface: `#F5F5F0` (off-white — clean, professional)
  - Text: `#2C2C2C` (near-black)
  - Muted: `#6B7280` (gray — secondary text)
- **Typography Scale:** 16px base, 1.5 line-height
- **Spacing:** 8px grid system

### File Structure
```
src/
  index.html        — Main HTML file (single-page)
  css/
    styles.css      — Main stylesheet
  js/
    main.js         — Main JavaScript file
  assets/
    images/         — Project and team images (placeholders acceptable)
```

### Constraints
- Static site only — no backend, no build tools required
- Must be mobile-responsive (breakpoints: 768px, 1024px)
- All source files in `src/` directory
- No external JavaScript frameworks (React, Vue, etc.)
